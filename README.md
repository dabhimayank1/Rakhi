# Bandhan — A Rakhi Made of Memories 🎀✨

A personalized Raksha Bandhan digital keepsake web app featuring:
- Personalized wishes and custom brother-sister letters
- 3D Interactive Memory Mirror Carousel with 8 custom photos
- Wall of Memories gallery with photo zoom
- Instant download of personalized Rakhi keepsake cards (PNG)

## 🚀 Live on Vercel
Deployable directly as a static web app on Vercel.

## 💻 Local Development
```bash
npm install
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
